# Usage
### Open Apple Music desktop app and go to:
File > Library > Export Library
- Save this file wherever you wish (Name dosen't matter)

### Download apple_music_to_md.py and run in vscode or whatever idk
- this should open a file picker
- Select the exported library.xml
- Select the output folder (This will create a LOT of files so make sure yo have the right spot)

### Open the selected folder as a vault in obsidian
- Sidebar > (Current Vault Name) > Manage Vaults > Open folder as vault
